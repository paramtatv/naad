Lossless · Bit-exact · Auditable to the bottom of the stack

Every lossless codec returns your samples unchanged — that is what the word means, and anyone promising you a warmer lossless format is selling you something else. What differs between them is what you can verify. Naad's entire decoder is 1,182 lines of Sanskrit, compiled to a 64-bit RISC machine, with no foreign code beneath it. You can read the whole thing in an afternoon.

For people who actually measure

Three claims we will not make.

That it sounds better

Lossless decoding returns the identical bitstream. Two correct lossless decoders produce byte-identical output, and no cable, format or file layout changes that. If a codec promises you a different sound, it is either not lossless or not honest.

That it is the fastest

Mature C decoders run far ahead of 6× real time. Naad is fast enough, with comfortable headroom on a 1 GHz core, and it gets there without a single line of C. Speed was the gate it had to pass, not the prize.

That it compresses harder

It reaches +0.1% of flac -8 — parity, on FLAC's own adversarial corpus, with Levinson–Durbin, apodisation and a full Rice partition-order search. Matching a twenty-year-tuned reference is the achievement; beating it is not claimed.

What we do claim

That you can check every one of these yourself.

Verification here means enumeration, not sampling. Where a format defines a space of codes, the test set contains all of them.

▪
All 64 subframe type codes

Not a selection. 39 legal codes and 25 reserved ones, each classified or refused. The reserved codes are refused rather than masked — a decoder that masks three bits and trusts them accepts a predictor order that was never written.

▪
All four frame-header code spaces

16 blocksize codes, 16 sample-rate codes, 16 channel assignments, 8 bit depths, and both escape forms displaced by a seven-octet frame number — because the escaped field sits after the number, not beside the code that triggers it.

▪
Both CRCs anchored externally

CRC-8 gives 0xF4 and CRC-16/UMTS gives 0xFEE8 over "123456789" — the published catalogue values. A CRC checked only against another implementation of the same polynomial agrees on every wrong polynomial too.

▪
Fourteen deliberate defects, each caught

The test suite is run against a sabotaged decoder — wasted bits ignored, the Rice parameter width hardcoded, the side channel not widened — and every mutation is caught at the exact case built to catch it.

▪
Two independent engines must agree

Every result is produced twice: once by an interpreter executing the Sanskrit source, once by the compiled RISC-V image. A green requires both. One engine agreeing with itself is not evidence.

▪
A foreign reference, on purpose

The oracle every result is checked against is written in another language entirely. A reference written in Sanskrit and built by the same compiler would be a twin, and a twin cannot be a witness.

The technology

Sassembly — a systems language written in Sanskrit.

Naad is not Sanskrit as decoration. Sassembly is a precise, royalty-free instruction set and language whose keywords, types and operators are Sanskrit words, and it compiles to 64-bit RISC-V. Its own compiler is written in it: the source compiles itself to an image byte-identical to the one that built it. That property — a reached fixpoint — is what makes the stack auditable rather than merely open.

For a codec, that matters in a specific and unglamorous way. The decoder never touches a floating-point number. Fitting the predictor is floating-point work and lives in the encoder; quantising those coefficients to integers plus a shift is the boundary, and everything after it is exact arithmetic. Two machines, two decades apart, return the same samples, because there is nothing in the path that could round differently.

And the vocabulary is load-bearing. निःशेषम् — niḥśeṣam, “with no remainder” — is the decoder's name, and it is also a precise description of what lossless means. नाद — nāda — is sound considered as vibration rather than as signal, the term the Indian tradition used for the thing itself. A field that named its concepts a few thousand years ago turns out to have named them well.
